# Amira Alsilowi | Technology Meets Art

Welcome to my personal portfolio! This website is a creative exhibition that combines my passion for Information Systems, business, and artistic expression (Arabic Calligraphy & Advertising Design).

## 🚀 Live Demo
[Click here to visit the live website](https://amiraalsilwi.github.io/My-Personal-Portfolio/)

## 🛠️ Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Flexbox, Grid, Animations)
- **Font Awesome** (For icons)
- **Google Fonts** (Playfair Display, Inter, Amiri, Aref Ruqaa)

##  Key Features
- **Zero JavaScript:** All interactions, including the mobile menu, image lightbox, and hover effects, are built using pure CSS techniques (Checkbox Hack, `:target` pseudo-class).
- **Artistic Gallery:** A masonry layout featuring a grayscale-to-color transition effect for artwork.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile screens.
- **Custom Design:** Asymmetric hero section with CSS `clip-path` and a custom glowing profile frame.

## 📂 Project Structure
- `index.html`: The main structure of the website.
- `css/style.css`: All styling, animations, and responsive rules.
- `images/`: Contains the logo, profile picture, cover, and artwork.
